# ExcelBomb v1.1.5 · Win7 批量行号与原格式合表

本次重点修复合表导出丢失样式的问题，增加批量 / 逐个设置数据开始行及单行备注处理。仅发布 Win7 安装包，macOS 使用包保留 v1.1.3，本地网页与离线文件同步更新。软件只在本机运行，不上传表格，不修改原文件。

## 本次更新

- **批量设置行号：** 上传多个文件后，可一次应用表头行和数据开始行到全部文件，仍可逐个修改；批量设置中留空的项目不更改。数据开始行留空时默认跟随表头，必须位于表头之后。
- **单行备注：** 自动识别备注，可选择“最后一行为备注”或“作为普通数据保留”。备注从明细中分离后移至导出表末，相同备注保留一份，不同备注分别保留，沿用原备注的样式与合并区域。
- **默认保留 XLSX 原格式：** 不再只按数据重建无样式表格。第一份文件提供标题、表头、多级表头及列宽；各份明细保留各自字体、颜色、填充、边框、对齐、数字格式和行高。补零编号按原单元格类型与显示格式保留。
- 保留可映射的合并单元格、常见条件格式、第一份表的 Excel 表格样式、冻结窗格和打印页面设置；原表没有筛选器时不额外添加。指定的数据开始行位于纵向合并区域中间时，保留相应文字及剩余区域。
- 继续修复异常空日期读取 / 导出错误，清理重复表头、页码、签字页脚和原表统计；仅对能确认求和的列重算一行总合计，相同业务记录不去重。

## 格式保留范围

完整的单元格样式与版式保留针对 **XLSX**。旧 XLS 请先用 Excel / WPS 另存为 XLSX；CSV 本身没有样式。也可明确取消“保留原表格式”，只合并数据。网页预览用于核对数据，不模拟完整 Excel 排版。

合并为一张表后，每列只能有一个列宽，以第一份文件为准；新增字段采用其来源文件列宽。若跨列合并区域在字段重排后无法保持，程序会报出来源和区域，不静默取消合并。图片、图表、宏、跨表公式与其他工作表不复制；一般公式使用已有缓存值，不执行通用 Excel 公式重算。拆表和 Lookup 的格式范围保持原有行为，仅保留数据及数字 / 日期格式。

## 下载与安装

| 附件 | 适用系统 |
| --- | --- |
| `ExcelBomb-Win7-x86-1.1.5.zip` | Windows 7 32 位专用。 |
| `ExcelBomb-Win7-1.1.5.zip` | Windows 7 32/64 位通用，自动选择对应程序。 |
| `SHA256SUMS.txt` | 两份 ZIP 的 SHA-256 校验值。 |

完整解压后，双击顶层 **`01-Install-ExcelBomb.exe`**。`00-Start-Here.html` 提供中文图文指引，`Support/` 为辅助文件夹，请保留到安装完成。安装到当前用户目录、创建桌面入口，默认启用登录后的后台自启，自启时不弹出网页。升级安装会验证并停止旧版 ExcelBomb 服务，然后替换程序。

安装器本身为 x86，内嵌 `asInvoker` 清单，无需管理员权限、联网、PowerShell、VBScript、Python、Node 或 Office。保留关闭 / 开启自启、卸载、免安装和诊断入口。本机地址为 `http://127.0.0.1:8769/`。

## 验证与兼容要求

- 字体、底色、边框、对齐、行高列宽、合并区域、备注、条件格式及冲突数字格式经过实际 XLSX 导出回读；测试表完成独立读取和原表 / 导出表渲染对照。
- 核对批量行号、逐个覆盖、末行备注、本地网页、离线入口、Win7 旧接口模拟、FileReader、IE 保存接口及后台线程降级路径；检查拆表和 Lookup 回归。
- 启动器固定 **Go 1.20.14、CGO=0**，x86 使用 softfloat；核对 x86 / x64 PE 架构、Windows GUI 6.1 子系统和 `asInvoker` 清单。
- 目标为 **Windows 7 SP1 + IE11 标准模式**或本机已有的兼容浏览器，不支持 IE8 / IE9 / IE10。
- **尚未在真实 Win7 / IE11 机器验证安装、登录自启与卸载。静态检查、交叉构建和现代浏览器接口模拟不等于真机验收。**

Win7 限制仍为单文件 10 MB、总加载 20 MB，每表最多 5 万条实际数据、1000 列、50 万个单元格；单次拆表最多 500 个文件。多余空白及纯格式区域不计入数据容量。刷新或关闭前请下载结果。
