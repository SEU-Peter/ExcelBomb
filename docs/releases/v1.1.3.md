# ExcelBomb v1.1.3 · 有效数据识别与全宽预览

修复普通表格因多余空白区域被误判为过大的问题，重新整理数据预览及拆表操作布局。提供 Mac、Win7 32 位专用和 Win7 32/64 位通用使用包，全部仅在本机运行，表格不上传。

## 本次更新

- **按实际数据读取 Excel：** 自动忽略空行、外围空列、纯格式单元格和不可见空白，不再按工作表声明的巨大范围直接拒绝文件；内部空白列、原始行号、有效的 0 / false、编号及数字和日期时间格式保留。
- **全宽数据预览：** 设置在上，预览在下，支持展开为接近全屏的窗口。默认每页 100 行，可选 25 / 50 / 100 / 200 / 500 行，并可搜索全部数据。
- **全部拆分分组连续展示：** 分组以多列清单显示，不需要翻页；支持搜索、改名、查看数据、合并及撤销。
- **整理“提取表头”区域：** 按钮紧随文件、工作表和表头行设置；右侧显示步骤提示，提取成功后才显示字段和全宽预览。
- Lookup 未匹配单元格继续保持空白；拆表文件名仍为 `名称-条目数.xlsx`，例如 `一室-23.xlsx`。

## 容量与验证范围

- 现代版：单文件 30 MB，每表最多 20 万条实际数据、1000 列、500 万个单元格。
- Win7：单文件 10 MB，总加载 20 MB，每表最多 5 万条实际数据、1000 列、50 万个单元格；单次 ZIP 最多 500 个文件，超过时可先合并分组。
- 已用 **40 列 × 685 行、685 列 × 40 行**及工作表声明范围达到 `XFD1048576` 的模拟文件，检查实际数据读取、685 个分组展示、原始行号、日期格式及实际下载回读。
- 已执行本地网页、离线入口和旧浏览器接口缺失模拟检查；Win7 程序固定使用 Go 1.20.14、CGO=0，核对 x86 / x64 架构、Windows GUI 6.1 子系统及 `asInvoker` 清单。

**开发环境为 Mac，尚未在真实 Win7 / IE11 上验证安装、登录自启与卸载。构建、静态检查和浏览器接口模拟不等于真机验收。** Win7 目标为 Windows 7 SP1 + IE11 标准模式或本机已有的兼容浏览器，不支持 IE8/9/10。

数据只保存在内存，刷新或关闭页面前请下载结果。导出保留数据及数字/日期格式，不保留宏、图表、合并单元格或其他原始样式；公式使用输入文件已有的缓存结果。
