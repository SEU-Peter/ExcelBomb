# ExcelBomb v1.1.0

首个 GitHub 双平台发布，提供 macOS 本地/离线版和独立 Win7 兼容版。GitHub 仓库名为 **ExcekBomb**；软件只在本机运行，表格不上传，不部署在线处理网站。

## 下载与使用

| 附件 | 用途 |
| --- | --- |
| `ExcelBomb-macOS-1.1.0.zip` | macOS 使用包，附启动脚本、离线 HTML、本地服务、使用说明和测试表格。 |
| `ExcelBomb-Win7-1.1.0.zip` | Win7 使用包，同时包含原生 x86 / x64 启动器、离线 HTML、诊断/关闭入口、说明和测试表格。 |
| `SHA256SUMS.txt` | 两个使用包的 SHA-256 校验值。 |

请下载 Assets 中的平台 ZIP 并**完整解压**；GitHub 自动生成的 Source code 是开发源码。

- **Mac：** 双击 `启动 ExcelBomb.command`，需要 Python 3；也可直接用现代浏览器打开 `ExcelBomb.html`，无需 Python 或服务。使用包不是签名 `.app`。
- **Win7：** 双击 `Start-ExcelBomb.cmd`，自动选择 32/64 位程序，无需安装 Python、Node、Go、Office 或额外运行库，不需要管理员权限。目标环境为 Windows 7 SP1 + IE11 标准模式，或本机已安装的兼容浏览器；IE8/9/10 不支持。
- 本地服务地址为 `http://127.0.0.1:8769/`。Win7 可通过 `Stop-ExcelBomb.cmd` 关闭自身服务，`Check-ExcelBomb.cmd` 生成诊断文件。
- 建议先用随包 `test/` 中的虚构表格体验三项功能。下载和首次取得源码需要网络，日常处理无需网络。

## 主要功能

- **拆表：** 自选工作表/表头行，按字段分组；可查看、搜索、分页、重命名、合并及撤销。文件按 `名称-条目数.xlsx` 导出，例如 `一室-23.xlsx`，页面预览与 ZIP 内实际名称一致。
- **合表：** 多文件选择，可拖动或用按钮调整顺序；按表头名称对齐，缺列留空，预览后导出。
- **Lookup：** 可选多个返回字段，设置重复值、空格和大小写规则；未匹配单元格真正留空，支持筛选/导出未匹配和重复记录。
- 默认保护前导零编号，保留普通数字及日期时间格式；替换确认、离页提醒、图文说明和后台处理进度随包提供。

## Win7 适配与验证范围

使用 Go 1.20.14、CGO=0 生成真正的 PE32 / PE32+ Windows GUI 启动器，最低子系统为 6.1。网页单独构建为 ES5，包含 IE11 文件读取/保存、Promise/集合、弹窗/折叠区、传统布局和 Worker 降级适配。

已完成核心实际 XLSX 读写测试、现代浏览器上传和下载回读、离线入口、旧接口缺失模拟、IE 保存接口、Worker 失败恢复、原生服务测试、PE 与压缩包检查。**当前开发机为 Mac，尚未在真实 Windows 7 / IE11 机器上执行；这些检查不等于真机验证。**

## 容量与限制

- 现代版：单文件 30 MB，每张输入表最多 20 万行、1000 列、500 万个单元格。
- Win7：单文件 10 MB，总加载 20 MB，每张输入表最多 5 万行、200 列、50 万个单元格；单次 ZIP 最多 500 份 Excel。
- 数据只保存在内存，刷新/关闭会清空；先下载再离开。无后台线程时较大文件可能短暂停顿。
- 统一导出 `.xlsx`，不保留宏、图表、合并单元格和其他原始样式；保留数字/日期格式。公式依赖输入文件已有的缓存结果，不执行公式重算。
