# ExcelBomb v1.1.2 · 解压后就知道怎么安装

这次优化 Win7 使用包的安装入口与说明。解压后顶层只有三个入口：

```text
ExcelBomb-Win7/
├── 00-Start-Here.html          中文图文安装说明
├── 01-Install-ExcelBomb.exe    双击这个安装
└── Support/                   辅助文件，请保留
```

**安装只需三步：右键 ZIP 完整解压 → 双击 `01-Install-ExcelBomb.exe` → 看到“安装完成”后从桌面 ExcelBomb 打开。**

`00-Start-Here.html` 用文件夹示意图标出唯一需要双击的程序，并说明 Windows 隐藏扩展名时的文件名称。不要在浏览器里寻找安装按钮；回到解压文件夹双击应用程序即可。

## 安装与使用

- 安装器本身为 x86、Go 1.20.14、CGO=0，保留 `asInvoker` 清单，无需管理员权限，无需额外运行库或联网。
- 安装到 `%LOCALAPPDATA%\ExcelBomb`，创建桌面入口，默认登录后后台自启；平时双击桌面入口打开网页。
- 免安装、自启开关、卸载、诊断脚本和虚构测试表格统一放在 `Support/`，正常安装无需打开该文件夹。卸载也可从控制面板「程序和功能」进行。
- 完整解压并保留 Support 与安装程序在同一文件夹；安装成功后可以删除原压缩包与解压文件夹。
- 安装器兼容新版收纳布局与旧版平铺目录，解压文件和脚本保留旧 Windows 兼容的命名与编码。

表格继续只在本机处理。拆表 `名称-条目数.xlsx`、Lookup 未匹配留空、合表排序等功能保持现有行为。

目标系统为 Windows 7 SP1 + IE11 标准模式或本机已有的兼容浏览器。已检查新版入口识别、安装资源定位、架构与清单、压缩包内容、离线说明页面及链接。**当前开发环境是 Mac，仍未在真实 Win7 / IE11 上完成安装、登录自启与卸载验证。**
