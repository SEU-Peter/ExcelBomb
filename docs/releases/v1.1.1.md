# ExcelBomb v1.1.1

Win7 版新增一键安装、桌面入口和登录自启，提供明确的 **32 位专用包**。Mac 版功能保持现状，随同发布同版本使用包。所有表格仍在本机处理，不上传，不部署在线网站。

## 一键安装与开机自启

1. **完整解压** ZIP 后，双击 **`Install-ExcelBomb.exe`**；也可使用同名 `.cmd` 入口。
2. 安装到当前用户的 `%LOCALAPPDATA%\ExcelBomb`，创建桌面 **ExcelBomb** 快捷方式。无需管理员权限，不依赖 PowerShell、VBScript、Python、Node、Go、Office 或额外运行库。
3. 默认开启**当前用户登录 Windows 后的后台自启**，不会每次弹出网页。使用时双击桌面入口，打开 `http://127.0.0.1:8769/`。安装完成后无需保留原解压文件夹。
4. `Disable-Autostart.cmd` 关闭自启，`Enable-Autostart.cmd` 恢复自启；关闭自启不会停止本次运行中的服务。`Stop-ExcelBomb.cmd` 只关闭自身服务。
5. `Uninstall-ExcelBomb.cmd` 或控制面板「程序和功能」可卸载，移除当前用户的自启项、桌面入口和安装文件。导出文件请保存到自己的文档目录。

需要免安装使用时，双击 `Start-ExcelBomb.cmd`；不会修改自启设置。两种模式共用本机端口，同一时间运行一个版本。升级安装会识别并关闭已有 ExcelBomb Win7 服务，端口被其他程序占用时会报告错误，不会终止其他软件。

自启失败信息写入安装目录 `logs/startup.log`，`Check-ExcelBomb.cmd` 可核对安装路径、注册的自启命令、架构和服务状态，不含表格内容。自启是登录后的用户程序，不是登录前的 Windows 系统服务。

## 保留的功能

拆表支持表头行选择、改名、合并、撤销和按 `名称-条目数.xlsx` 导出；合表支持拖动排序和按字段对齐；Lookup 未匹配单元格真正留空，并提供重复记录、未匹配记录的筛选与导出。数字/日期格式、前导零保护、图文说明和虚构测试表格继续保留。

## 验证与限制

启动器固定 Go 1.20.14、CGO=0，x86 使用 softfloat。核对 x86 安装器、x86 / x64 主程序的 PE 架构、Windows GUI 6.1 子系统和内嵌 `asInvoker` 清单；以原生 API 注册当前用户自启和桌面快捷方式。

已检查安装架构选择、缺失/错误程序拒绝、中文/空格路径、带引号自启命令、安装文件更新、卸载脚本流程、旧版服务识别与关闭，并执行既有本地网页和兼容路径测试。

**当前环境是 Mac，尚未在真实 Win7 / IE11 上执行安装、登录自启与卸载。交叉构建、逻辑测试和浏览器接口模拟不等于真机验收。** 建议先使用 `test/` 中的虚构表格，并在 Win7 电脑上重启登录，核对桌面入口和自启状态。

容量限制保持不变：Win7 单文件 10 MB、总加载 20 MB、每表最多 5 万行/200 列/50 万单元格、单 ZIP 最多 500 份 Excel；现代版单文件 30 MB、每表最多 20 万行/1000 列/500 万单元格。数据只在内存中，刷新/关闭会清空；导出不保留宏、图表、合并单元格及其他原样式，公式使用已有缓存值。
