# ExcelBomb v1.1.4 · Win7 合表修复与自动整理

本次仅发布 Windows 7 安装包，包含最新合表修复。macOS 继续使用 [v1.1.3](https://github.com/SEU-Peter/ExcelBomb/releases/tag/v1.1.3)；该旧包不包含本次修复。软件只在本机运行，不提供在线处理网站，表格不上传，原文件不修改。

## 本次更新

- 修复可复现的异常空日期导致的 `cannot read property match of null` 读取或导出错误，避免因一个异常日期单元格丢失整张工作表。
- 合表默认自动识别表头，可手动改行号；支持合并单元格形成的多级表头，按字段名称对齐列，忽略表头空格、换行和大小写，缺失字段留空。
- 自动清理重复分页表头、页码、打印时间、制表签字等结构行及原表合计 / 小计。内容相同的业务记录仍然保留。
- 原统计与明细求和吻合，或原统计使用 SUM / 求和型 SUBTOTAL 时，对相应字段重新生成一行总合计；编号、日期、单价、比例不相加。不执行通用 Excel 公式重算。
- 可选择只保留明细或关闭清理，页面显示清理数量，并提供原文件、原行号及被移除内容的清理明细。
- 保留拖动排序、全宽预览、全部拆分分组展示、`名称-条目数.xlsx` 文件名和 Lookup 未匹配留空等功能。

## 下载与安装

| 附件 | 适用系统 |
| --- | --- |
| `ExcelBomb-Win7-x86-1.1.4.zip` | Windows 7 32 位专用，32 位电脑优先下载。 |
| `ExcelBomb-Win7-1.1.4.zip` | Windows 7 32/64 位通用，自动检测并安装对应程序。 |
| `SHA256SUMS.txt` | 两份 ZIP 的 SHA-256 校验值。 |

仓库为私有开发仓库，下载需登录有访问权限的 GitHub 账号。请下载 Assets 中的 ZIP；自动生成的 Source code 是开发源码。

1. 将 ZIP **完整解压**，不要在压缩包内运行。
2. 双击顶层唯一的 **`01-Install-ExcelBomb.exe`**。`00-Start-Here.html` 是中文图文说明，`Support/` 是辅助文件夹，请保留到安装完成。
3. 安装到当前用户目录并创建桌面入口。以后双击桌面 **ExcelBomb**，访问 `http://127.0.0.1:8769/`。

两个包的安装器均为原生 x86 / PE32，内嵌 `asInvoker` 清单，无需管理员权限。默认开启当前用户登录 Windows 后后台自启，登录时不弹出网页。保留关闭 / 开启自启、卸载、免安装和诊断入口，无需联网、PowerShell、VBScript、Python、Node、Office 或额外运行库。升级安装会验证并停止已有的 ExcelBomb Win7 服务，替换为本版程序。

## 兼容要求与验证范围

- 目标系统：**Windows 7 SP1 + IE11 标准模式**，或本机已安装的兼容浏览器；不支持 IE8 / IE9 / IE10。
- 启动器固定 Go 1.20.14、CGO=0，x86 使用 softfloat；核对 x86 / x64 架构、Windows GUI 6.1 子系统、静态导入和安装器 `asInvoker` 清单。
- 网页经过 ES5 语法检查、实际 XLSX 上传 / 导出回读、离线入口及旧浏览器接口缺失模拟，覆盖 FileReader、IE 保存接口、弹窗、无线程与线程失败恢复路径；启动与安装逻辑执行宿主测试。
- **开发环境为 Mac，尚未在真实 Windows 7 / IE11 上验证安装、登录自启与卸载。构建、静态检查和接口模拟不等于真机验收。** 建议先使用 `Support/test/` 的虚构测试表格核对。
- Win7 单文件 10 MB、总加载 20 MB，每表最多 5 万条实际数据、1000 列、50 万个单元格；单次拆表最多 500 份文件。外围空白和纯格式区域不计入数据容量。

数据保存在内存中，刷新或关闭前请下载结果。导出保留数据值及数字 / 日期格式，不保留宏、图表、合并单元格或其他原始样式。未能确认统计规则时输出完整明细，可从清理明细核对原统计。
