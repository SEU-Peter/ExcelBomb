一、解压后先看这里
顶层只有三个入口：
00-Start-Here.html          图文安装说明，双击阅读
01-Install-ExcelBomb.exe   唯一的安装程序，双击安装
Support                   辅助文件，请保留；正常安装无需打开

从 ZIP 右键“全部提取”后，双击 01-Install-ExcelBomb.exe，等待“安装完成”，以后从桌面 ExcelBomb 打开。

二、开始使用
1. 将 ZIP 完整解压到桌面或文档文件夹，不要直接在压缩包内运行。
2. 推荐双击 01-Install-ExcelBomb.exe 一键安装，创建桌面入口并开启登录自启；安装器兼容 Win7 32 位。
3. 浏览器地址为 http://127.0.0.1:8769/ 。全部文件在本机处理，不上传，不需要联网。
4. 不需要安装 Python、Node、Java、Office 或额外运行库，也不需要管理员权限。
5. 请使用 Windows 7 SP1，配合 IE11 标准模式，或本机已有的兼容浏览器。IE8、IE9、IE10 不支持。

优先打开本机已安装的 Chrome、Edge 或 Firefox；未找到时使用默认浏览器。
如果默认浏览器过旧，请用 IE11 标准模式或已有兼容浏览器手动打开上述本机地址。
本包不会下载、安装或更改默认浏览器。
需要免安装体验时，打开 Support 文件夹，双击 Start-ExcelBomb.cmd，自动选择可用架构并打开浏览器，不设置自启。

三、一键安装和开机自启
完整解压后，双击 01-Install-ExcelBomb.exe（安装器本身是 32 位，兼容 Win7 32 位）。
安装到当前用户 %LOCALAPPDATA%\ExcelBomb，无需管理员权限。
通用包会检测系统位数并安装对应程序；x86 专用包始终安装 32 位程序。
安装后桌面出现 ExcelBomb 入口，并默认在当前用户登录 Windows 后后台自启，不会自动弹出网页。
以后双击桌面入口即可使用；安装完成后无需保留原解压文件夹。
Disable-Autostart.cmd 关闭自启；Enable-Autostart.cmd 恢复自启。关闭自启不会停止当前服务。
Uninstall-ExcelBomb.cmd 或控制面板“程序和功能”可卸载，移除自启、桌面入口和安装文件。
请将导出的业务文件放在自己的文档目录，不要存入程序安装目录。
自启失败日志：安装目录 logs\startup.log；Check-ExcelBomb.cmd 可检查注册的自启命令。
安装和自启不依赖 PowerShell、VBScript、计划任务、Python 或额外运行库。
仅双击 Start-ExcelBomb.cmd 为免安装运行，不会注册自启。安装和免安装共用同一端口。
升级安装会先验证并停止已有 ExcelBomb Win7 服务，不会终止其他软件。
自启发生在用户登录后，不是登录前的系统服务。

四、关闭与检查
关闭浏览器页面不会停止本地服务。需要停止时双击 Stop-ExcelBomb.cmd。
重复启动会复用现有的 ExcelBomb Win7 服务，不会重复运行多个服务。
如果端口被其他程序占用，会明确提示，并且不会打开或关闭不属于 ExcelBomb 的服务。
辅助入口均位于 Support 文件夹。Check-ExcelBomb.cmd 会在该文件夹生成 ExcelBomb-Diagnostics.txt，不包含表格内容。
遇到问题时，请记录 Windows 位数、浏览器版本、提示文字；可附页面截图和诊断文件。

五、离线 HTML
Support 文件夹中的 ExcelBomb-Win7.html 可直接用兼容浏览器打开，不需要启动程序。
IE11 直接打开本地 HTML 时，可能需要允许本地脚本运行；不要更改全局安全设置。
IE11 本地文件模式通常使用兼容处理模式，较大文件建议通过 Start-ExcelBomb.cmd 启动本地服务，启用后台线程。
无法创建后台线程时会自动使用兼容处理路径。兼容路径处理较大的文件时可能短暂停顿，请等待完成。

六、功能与现有版本一致
- 拆表：工作表和表头行可选；全部分组连续展示，可改名、合并、查看分组数据、撤销和搜索。
- 文件名自动采用“名称-条目数.xlsx”，例如“一室-23.xlsx”“二室-34.xlsx”。预览与 ZIP 内名称一致。
- 合表：自动识别表头，可手动指定；可拖动或上下排序，按字段名称对齐，缺失字段留空。
- 合表默认清理重复分页表头、页码、打印日期、制表签字等结构行及原表合计 / 小计；仅对已确认求和的列重算一行总合计，不相加编号、日期、单价或比例。
- 内容相同的业务记录会保留。可查看清理明细追溯原文件和行号；也可选择只保留明细，或关闭自动清理按原内容合并。
- 修复异常空日期单元格触发的 .match 读取 / 导出错误，原始文件不会被修改。
- Lookup：未匹配的单元格真正留空；支持筛选和导出未匹配记录，查看及导出重复值。
- 默认保护编号前导零；普通金额保持数值，保留数字、日期和时间格式。
- 替换文件或用示例覆盖已有内容时会确认；有未下载修改时离开页面会提醒。
- 页面右上角有分步骤图文使用说明。
- 数据预览使用全宽布局，可展开核对，默认每页 100 行，可选到 500 行；分组全部连续展示，无需翻页。
- 自动识别有效数据，忽略多余空行、外围空列及纯格式区域；原始行号、零、false、编号和日期格式会保留。

七、Win7 内存限制
为控制 32 位浏览器内存占用，本兼容版使用更保守的限制：
单文件 10 MB，同时加载总计 20 MB；每张表最多 5 万条实际数据、1000 列，实际数据区域最多 50 万个单元格。空行、外围空列及纯格式单元格自动忽略，不按声明范围计数。
单次 ZIP 最多生成 500 个 Excel。文件较多时，请合并分组或分批处理。
切换工具会保留已选文件；需要释放内存时，请先下载结果，再刷新页面。
上述限制只针对 Win7 包，Mac 版本保持原有限制与行为。

八、测试范围与明确限制
已检查全部运行脚本为 ES5 语法，并提供旧浏览器的集合、Promise、FileReader、弹窗、折叠区和保存接口兼容层。
已在现代浏览器中完成实际上传与下载回读，并模拟缺失旧浏览器接口，验证无后台线程和 IE 保存接口路径。
启动器固定使用 Go 1.20.14、关闭 CGO，分别生成真正的 PE32 和 PE32+ 可执行文件，不依赖目标电脑安装 Go。
Go 官方说明：Go 1.20 是支持 Windows 7 的最后一个系列：https://go.dev/doc/go1.20
当前开发环境是 Mac，尚未在真实 Windows 7 / IE11 机器上执行本包、安装、自启及卸载。模拟及静态检查不等于真机验证。
Support/test 文件夹中的表格均为虚构测试数据，可先用它们核对三项功能，再处理正式文件。

导出保留数据值及数字/日期格式，不保留其他原始样式、宏、图表或合并单元格；一般公式依赖已有缓存结果，不执行通用公式重算，合表可按明细重新汇总已确认的 SUM / 求和型 SUBTOTAL 统计列。
支持 XLSX、XLS、CSV；旧编码 CSV 建议先另存为 XLSX。原始文件不会被修改。
