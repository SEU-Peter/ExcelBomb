ExcelBombWindows 7 · 本地版 · 32 位 / 64 位

三步安装，之后从桌面打开。

只需双击下面标出的安装程序。无需管理员权限，也不用另外安装运行库。

1

先把压缩包完整解压

右键下载的 ZIP → 选择“全部提取”或“解压到…” → 打开解压后的文件夹。

请从解压后的文件夹运行，保留旁边的 Support 文件夹。

2

双击唯一的安装程序

01-Install-ExcelBomb.exe

文件类型是“应用程序”。隐藏了后缀名时，它会显示为“01-Install-ExcelBomb”。

3

看到“安装完成”后，从桌面使用

安装完成会打开工作台，并创建桌面 ExcelBomb 快捷方式。以后双击桌面图标即可。

默认已开启登录 Windows 后后台自启。每次登录不会弹出网页，使用时从桌面打开。

现在就可以安装：回到解压后的文件夹，双击 01-Install-ExcelBomb.exe。这份说明里不需要再点击任何安装按钮。

我的电脑是 32 位，可以安装吗？

可以，安装器本身就是 32 位。通用包自动选择对应程序；x86 专用包安装 32 位程序，无需手动打开 bin 文件夹选择。

安装后，需要保留解压文件夹吗？

确认桌面入口可以使用后，可以删除原压缩包和解压文件夹。已安装的程序会保留在当前用户的程序目录中。

暂时不想安装，或者需要管理自启？

打开 Support 文件夹，按需要选择下面的入口。正常安装只需上面的三步。

免安装体验
Start-ExcelBomb.cmd
关闭 / 恢复自启
Disable-Autostart.cmd / Enable-Autostart.cmd
停止后台服务
Stop-ExcelBomb.cmd
检查运行问题
Check-ExcelBomb.cmd
卸载程序
Uninstall-ExcelBomb.cmd，或控制面板 → 程序和功能 → ExcelBomb

打不开页面或按钮没有反应？

需要 Windows 7 SP1，配合 IE11 标准模式或本机已有的兼容浏览器。IE8 / IE9 / IE10 不支持。如果提示文件不完整，请重新完整解压，确保安装程序旁仍有 Support 文件夹。
