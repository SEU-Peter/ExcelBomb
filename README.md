# ExcelBomb

一个只在本机运行的 Excel 工作台，用可视化操作完成拆表、合表和 Lookup。无需安装 Office，支持读取 `.xlsx`、`.xls`、`.csv`，统一导出 `.xlsx`。

**[下载最新版本](https://github.com/SEU-Peter/ExcekBomb/releases/latest)** · [v1.1.3 发布说明](docs/releases/v1.1.3.md) · [开发与测试说明](DEVELOPMENT.md)

本项目的 GitHub 仓库名为 **ExcekBomb**，软件名称为 **ExcelBomb**。GitHub 用于源码管理与安装包分发；软件仅在本地运行，不提供在线处理网站。选择的表格在浏览器内处理，不上传到服务器，原文件不会被修改。

## 下载与启动

请在 Release 的 **Assets** 中下载对应平台的 ZIP；GitHub 自动生成的「Source code」是开发源码，不是使用包。完整解压后再启动。

| 系统 | 下载文件 | 启动方式 |
| --- | --- | --- |
| macOS | `ExcelBomb-macOS-1.1.3.zip` | 双击 `启动 ExcelBomb.command`；需要 Python 3。也可直接用现代浏览器打开 `ExcelBomb.html`，无需 Python 和本地服务。 |
| Windows 7 32 位 | `ExcelBomb-Win7-x86-1.1.3.zip` | 完整解压后双击顶层唯一的 `01-Install-ExcelBomb.exe`。`00-Start-Here.html` 提供中文图文安装指引。 |
| Windows 7 32/64 位通用 | `ExcelBomb-Win7-1.1.3.zip` | 安装器本身为 32 位，自动检测系统并选择对应程序；无需安装 Python、Node、Go、Office 或额外运行库。 |

启动器打开 `http://127.0.0.1:8769/`，服务只监听本机。所有脚本、字体和处理库均随包附带，使用时无需联网。两个平台都附带虚构测试表格，Mac 位于 `test/`，Win7 位于 `Support/test/`。

**macOS：** 使用当前版本的 Safari、Chrome、Edge 或 Firefox。发行包是本地网页与启动脚本的组合，不是经过签名的 `.app` 安装器。没有 Python 3 时，直接打开随包的离线 HTML 即可。关闭页面不会停止通过启动器开启的本地服务。

**Win7：** 目标环境为 Windows 7 SP1，配合 IE11 标准模式或本机已安装的兼容浏览器；不支持 IE8、IE9、IE10。可通过 `Stop-ExcelBomb.cmd` 关闭自身服务，`Check-ExcelBomb.cmd` 生成不含表格内容的诊断文件。当前包已完成静态检查和现代浏览器兼容路径测试，**尚未在真实 Win7 / IE11 机器上验证**，建议先用附带表格核对。

### Win7 一键安装与开机自启

解压后的顶层只有三个入口：

```text
ExcelBomb-Win7/
├── 00-Start-Here.html          中文图文安装说明
├── 01-Install-ExcelBomb.exe    双击这个安装
└── Support/                   辅助文件，正常安装不用打开
```

![Win7 中文安装指引](docs/images/installer-guide.png)

完整解压 ZIP 后，双击 **`01-Install-ExcelBomb.exe`**。程序安装到当前用户的 `%LOCALAPPDATA%\ExcelBomb`，创建桌面 **ExcelBomb** 快捷方式，并默认开启当前用户登录 Windows 后的后台自启；不自动弹出网页。使用时双击桌面入口即可，无需保留原解压文件夹。安装只写当前用户目录和注册表，无需管理员权限。

免安装启动、关闭自启、卸载和诊断入口统一收在 `Support/`，安装后也可在安装目录找到这些管理入口。

- 安装器本身为原生 **x86 / PE32**，兼容 Win7 32 位。通用包在 64 位系统中安装 x64 程序；x86 专用包始终安装 32 位程序。
- `Disable-Autostart.cmd`：关闭登录自启，不停止当前服务。
- `Enable-Autostart.cmd`：重新开启已安装版本的登录自启。
- `Uninstall-ExcelBomb.cmd` 或控制面板「程序和功能」：停止自身服务，移除自启、桌面入口和安装文件。请把导出的业务文件放在自己的文档目录。
- 仅双击 `Start-ExcelBomb.cmd` 是免安装使用，不会注册自启；安装与免安装模式共享本机端口，同一时间运行一个版本。
- 自启失败信息写入安装目录 `logs/startup.log`，诊断文件可核对安装位置、自启命令和服务状态。自启发生在用户登录后，不是登录前的系统服务。

安装和自启均无需 PowerShell、VBScript、计划任务或联网。新版安装会先验证并停止已有的 ExcelBomb Win7 服务；端口被其他软件占用时会报告问题。

## 三种操作

### 拆表

1. 选择文件、工作表和表头行，点击提取字段。表头行默认是第一行。
2. 选择一个字段生成分组，全部分组以多列清单连续展示，无需翻页；可搜索、查看数据、重命名，或选择多个分组后合并，操作支持撤销。
3. 核对最终文件名，确认后下载 ZIP。每组生成一张 Excel，例如 `一室-23.xlsx`、`二室-34.xlsx`。数字代表数据条目数，不包括表头；特殊字符和重名会提前处理，预览与实际下载保持一致。

### 合表

1. 选择多份文件，为每个文件指定工作表和表头行。
2. 拖动调整顺序，也可点击上下按钮。
3. 预览结果后导出。列按表头名称对齐，缺失字段留空。

### Lookup

1. 选择主表、参照表和各自的匹配字段。
2. 勾选一个或多个返回字段，按需设置重复值、空格和大小写处理方式。
3. 查看匹配统计与结果，可筛选、单独导出未匹配记录，核对或导出重复值。

未匹配的返回单元格保持真正空白，不填入“未匹配”等文字。默认保护 `00001` 这类补零编号；普通金额仍保持数值，数字及日期时间格式随导出保留。页面右上角提供分步骤图文使用说明。

数据预览使用整页宽表，默认每页 100 行，可选 25/50/100/200/500 行，并可展开为接近全屏的窗口核对。

## 容量与数据说明

| 限制 | macOS / 现代浏览器版 | Win7 兼容版 |
| --- | --- | --- |
| 单个输入文件 | 30 MB | 10 MB |
| 同时加载文件总量 | 受浏览器可用内存限制 | 20 MB |
| 单张输入工作表 | 20 万条实际数据、1000 列 | 5 万条实际数据、1000 列 |
| 单表读取区域 | 500 万个单元格，仅统计实际数据行 | 50 万个单元格，仅统计实际数据行 |
| 单次拆表 ZIP | 受浏览器可用内存限制 | 最多 500 份 Excel |

- 自动识别实际非空行与有效列，跳过空行、纯格式单元格及外围空白列；不使用 Excel 声明范围直接判断容量。内部空白单元格、有效的 0 / false 和原始行号会保留。
- 数据保存在内存中，刷新或关闭页面后清空；请及时下载结果。
- 导出保留数据值与数字、日期时间格式，不保留其他原样式、宏、图表和合并单元格。
- 公式使用输入文件已有的缓存结果，不执行 Excel 公式重算；缺少缓存的公式结果可能为空。
- 旧编码 CSV 出现乱码时，可先在 Excel 中另存为 XLSX。
- 后台线程不可用时，Win7 版自动切换兼容处理路径；较大文件可能短暂停顿。
- Release 附件提供 `SHA256SUMS.txt` 校验文件；用 macOS 的 `shasum -a 256` 或 Windows 的 `certutil -hashfile 文件名 SHA256` 可核对下载内容。

## 源码与第三方组件

现代版实现位于 `site/dist/`，Win7 独立适配与原生启动器位于 `site/win7/`。克隆、构建、测试和双平台打包命令见 [DEVELOPMENT.md](DEVELOPMENT.md)。仓库不包含云端部署流程。

运行资源包括 SheetJS CE 0.20.3、JSZip 3.10.1、Pacifico 与 DM Sans 字体；Win7 还使用 core-js 兼容层及 Go 标准库。各自许可证随使用包提供，源码中的网页资源许可证见 [site/dist/vendor/licenses](site/dist/vendor/licenses)。
