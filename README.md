# ExcelBomb

一个在浏览器中处理数据的 Excel 工作台，支持 GitHub Pages 在线访问及本地 / 离线运行，用可视化操作完成拆表、合表和 Lookup。无需安装 Office，支持读取 `.xlsx`、`.xls`、`.csv`，统一导出 `.xlsx`。

**[在线使用](https://seu-peter.github.io/ExcelBomb/)** · [离线单文件（可另存为）](https://seu-peter.github.io/ExcelBomb/ExcelBomb.html) · **[下载最新 Win7 版](https://github.com/SEU-Peter/ExcelBomb/releases/latest)** · [v1.1.5 发布说明](docs/releases/v1.1.5.md) · [开发与测试说明](DEVELOPMENT.md)

GitHub 仓库与软件名称均为 **ExcelBomb**。仓库公开维护源码，通过 GitHub Pages 提供在线入口，通过 Release 分发安装包。在线版和本地版都在当前浏览器内读取和处理表格，不上传表格内容，原文件不会被修改。

## 当前版本：Win7 v1.1.5 / macOS v1.1.3

当前网页与离线单文件使用最新 v1.1.5 功能代码，包含批量行号、备注及原格式合表。已发布的 Win7 安装包为 v1.1.5；macOS 安装包保留 v1.1.3，旧包不含本次合表更新，Mac 用户可使用在线版或最新离线单文件。

- **批量设置数据开始行：** 可一次应用表头行和数据开始行到全部文件，仍可逐个调整。
- **保留原表格式：** 合表默认保留 XLSX 的字体、颜色、边框、对齐、数字格式、行高、列宽、表头及有效合并区域；第一份文件提供表头和列宽，各份明细保留各自样式。
- **单行备注表尾：** 自动识别备注，也可指定最后一行为备注；导出时移至表末，相同备注保留一份，不同备注分别保留。
- **合表自动整理：** 自动识别表头，清理重复分页表头、页码、打印时间和制表签字等结构行及原表合计 / 小计。
- **确认后重新汇总：** 对可确认求和的列重算一行总合计，不相加编号、日期、单价和比例；内容相同的业务记录仍保留。可查看清理明细，或选择只保留明细、关闭清理。
- **异常空日期兼容：** 修复可复现的 `.match` 读取和导出错误，兼容异常空日期单元格，原文件保持不变。

以下 v1.1.3 的改进继续保留：

- **有效数据识别：** 自动忽略多余空行、外围空列及纯格式区域，避免普通表格因工作表声明范围过大而无法处理。已用 40 列 × 685 行、685 列 × 40 行及声明范围覆盖整张工作表的模拟文件验证。
- **全宽预览：** 文件设置放在上方，数据表格使用下方完整宽度，支持展开核对；默认每页 100 行，可选到 500 行。
- **全部分组展示：** 拆分结果以多列清单连续显示，不再分页，保留搜索、改名、合并和撤销。
- **表头提取布局：** “提取表头”按钮紧随文件、工作表与表头行设置；提取完成后显示字段和数据预览。

完整变更见 [v1.1.5 发布说明](docs/releases/v1.1.5.md)和 [v1.1.3 发布说明](docs/releases/v1.1.3.md)。下方合表说明对应 v1.1.5 Win7 包与最新本地源码，macOS v1.1.3 旧包不含本次合表修复。

## 下载与启动

请在 Release 的 **Assets** 中下载对应平台的 ZIP；GitHub 自动生成的「Source code」是开发源码，不是使用包。完整解压后再启动。

| 系统 | 下载文件 | 启动方式 |
| --- | --- | --- |
| macOS | [下载 Mac 版](https://github.com/SEU-Peter/ExcelBomb/releases/download/v1.1.3/ExcelBomb-macOS-1.1.3.zip) | 双击 `启动 ExcelBomb.command`；需要 Python 3。也可直接用现代浏览器打开 `ExcelBomb.html`，无需 Python 和本地服务。 |
| Windows 7 32 位 | [下载 Win7 x86 版](https://github.com/SEU-Peter/ExcelBomb/releases/download/v1.1.5/ExcelBomb-Win7-x86-1.1.5.zip) | 完整解压后双击顶层唯一的 `01-Install-ExcelBomb.exe`。`00-Start-Here.html` 提供中文图文安装指引。 |
| Windows 7 32/64 位通用 | [下载 Win7 通用版](https://github.com/SEU-Peter/ExcelBomb/releases/download/v1.1.5/ExcelBomb-Win7-1.1.5.zip) | 安装器本身为 32 位，自动检测系统并选择对应程序；无需安装 Python、Node、Go、Office 或额外运行库。 |

仓库现已公开，源码和 Release 安装包可直接访问。GitHub Pages 提供现代浏览器版；Win7 用户请使用上方的独立兼容包。

启动器打开 `http://127.0.0.1:8769/`，服务只监听本机。所有脚本、字体和处理库均随包附带，使用时无需联网。两个平台都附带虚构测试表格，Mac 位于 `test/`，Win7 位于 `Support/test/`。

**macOS：** 使用当前版本的 Safari、Chrome、Edge 或 Firefox。发行包是本地网页与启动脚本的组合，不是经过签名的 `.app` 安装器。没有 Python 3 时，直接打开随包的离线 HTML 即可。关闭页面不会停止通过启动器开启的本地服务。

**Win7：** 目标环境为 Windows 7 SP1，配合 IE11 标准模式或本机已安装的兼容浏览器；不支持 IE8、IE9、IE10。可通过 `Stop-ExcelBomb.cmd` 关闭自身服务，`Check-ExcelBomb.cmd` 生成不含表格内容的诊断文件。当前包已完成静态检查和现代浏览器兼容路径测试，**尚未在真实 Win7 / IE11 机器上验证**，建议先用附带表格核对。

### Win7 一键安装与开机自启

解压后的顶层只有三个入口：

```text
ExcelBomb-Win7/
├── 00-Start-Here.html          中文图文安装说明
├── 01-Install-ExcelBomb.exe    双击这个安装
└── Support/                   辅助文件，正常安装不用打开
```

![Win7 中文安装指引](docs/images/installer-guide.png)

完整解压 ZIP 后，双击 **`01-Install-ExcelBomb.exe`**。程序安装到当前用户的 `%LOCALAPPDATA%\ExcelBomb`，创建桌面 **ExcelBomb** 快捷方式，并默认开启当前用户登录 Windows 后的后台自启；不自动弹出网页。使用时双击桌面入口即可，无需保留原解压文件夹。安装只写当前用户目录和注册表，无需管理员权限。

免安装启动、关闭自启、卸载和诊断入口统一收在 `Support/`，安装后也可在安装目录找到这些管理入口。

- 安装器本身为原生 **x86 / PE32**，兼容 Win7 32 位。通用包在 64 位系统中安装 x64 程序；x86 专用包始终安装 32 位程序。
- `Disable-Autostart.cmd`：关闭登录自启，不停止当前服务。
- `Enable-Autostart.cmd`：重新开启已安装版本的登录自启。
- `Uninstall-ExcelBomb.cmd` 或控制面板「程序和功能」：停止自身服务，移除自启、桌面入口和安装文件。请把导出的业务文件放在自己的文档目录。
- 仅双击 `Start-ExcelBomb.cmd` 是免安装使用，不会注册自启；安装与免安装模式共享本机端口，同一时间运行一个版本。
- 自启失败信息写入安装目录 `logs/startup.log`，诊断文件可核对安装位置、自启命令和服务状态。自启发生在用户登录后，不是登录前的系统服务。

安装和自启均无需 PowerShell、VBScript、计划任务或联网。新版安装会先验证并停止已有的 ExcelBomb Win7 服务；端口被其他软件占用时会报告问题。

## 三种操作

### 拆表

1. 选择文件、工作表和表头行，点击设置下方的 **提取表头**。表头行默认是第一行。
2. 选择一个字段生成分组，全部分组以多列清单连续展示，无需翻页；可搜索、查看数据、重命名，或选择多个分组后合并，操作支持撤销。
3. 核对最终文件名，确认后下载 ZIP。每组生成一张 Excel，例如 `一室-23.xlsx`、`二室-34.xlsx`。数字代表数据条目数，不包括表头；特殊字符和重名会提前处理，预览与实际下载保持一致。

### 合表

1. 选择多份文件，默认自动识别表头；可在“批量设置行号”中填写表头行和数据开始行，点击“应用到全部文件”。也可逐个修改，留空的数据开始行默认跟随表头。每个文件选择一张工作表。网页中多级表头整理为字段便于核对，原格式导出保留第一份文件的多级表头。
2. 拖动调整顺序，也可点击上下按钮。默认清理重复表头、页码、打印时间、制表签字等结构行及原表合计 / 小计。表尾是一行备注时可选择“最后一行为备注”；备注在导出表末保留，相同内容保留一份。
3. 点击 **合并并预览**，列按名称对齐（忽略表头空格、换行和大小写），缺失字段留空。只有原统计与明细求和吻合，或原统计使用 SUM / 求和型 SUBTOTAL 时，才将相应字段重新汇总为一行总合计；编号、日期、单价和比例等不相加。可改为只保留明细，或关闭自动清理按原内容合并。
4. 核对预览后下载 Excel。页面显示清理数量，可点击 **查看清理明细** 追溯原文件与行号。内容相同的业务记录仍会保留，不会当作重复记录删除。

### Lookup

1. 选择主表、参照表和各自的匹配字段。
2. 勾选一个或多个返回字段，按需设置重复值、空格和大小写处理方式。
3. 查看匹配统计与结果，可筛选、单独导出未匹配记录，核对或导出重复值。

未匹配的返回单元格保持真正空白，不填入“未匹配”等文字。默认保护 `00001` 这类补零编号；普通金额仍保持数值，数字及日期时间格式随导出保留。页面右上角提供分步骤图文使用说明。

数据预览使用整页宽表，默认每页 100 行，可选 25/50/100/200/500 行，并可展开为接近全屏的窗口核对。

## 容量与数据说明

| 限制 | macOS / 现代浏览器版 | Win7 兼容版 |
| --- | --- | --- |
| 单个输入文件 | 30 MB | 10 MB |
| 同时加载文件总量 | 受浏览器可用内存限制 | 20 MB |
| 单张输入工作表 | 20 万条实际数据、1000 列 | 5 万条实际数据、1000 列 |
| 单表读取区域 | 500 万个单元格，仅统计实际数据行 | 50 万个单元格，仅统计实际数据行 |
| 单次拆表 ZIP | 受浏览器可用内存限制 | 最多 500 份 Excel |

- 自动识别实际非空行与有效列，跳过空行、纯格式单元格及外围空白列；不使用 Excel 声明范围直接判断容量。内部空白单元格、有效的 0 / false 和原始行号会保留。
- 数据保存在内存中，刷新或关闭页面后清空；请及时下载结果。
- 合表默认保留 XLSX 单元格样式、行高列宽、第一份表的标题/表头、有效合并区域、常见条件格式、首表 Excel 表格样式及打印页面设置。不同文件的列宽冲突时以第一份文件为准；数据行沿用各自源文件样式。原合并区域若因字段重排无法保留，会明确报错，不静默取消合并。
- 旧 XLS 保留原格式需先用 Excel / WPS 另存为 XLSX；CSV 没有样式。也可明确取消“保留原表格式”，只合并数据。拆表和 Lookup 仍仅保留数据及数字/日期格式；图片、图表、宏及跨表公式不复制。
- 公式通常使用输入文件已有的缓存结果，不执行通用 Excel 公式重算；缺少缓存的公式结果可能为空。合表可根据明细重新汇总已确认的 SUM / 求和型 SUBTOTAL 统计列。
- 旧编码 CSV 出现乱码时，可先在 Excel 中另存为 XLSX。
- 后台线程不可用时，Win7 版自动切换兼容处理路径；较大文件可能短暂停顿。
- Release 附件提供 `SHA256SUMS.txt` 校验文件；用 macOS 的 `shasum -a 256` 或 Windows 的 `certutil -hashfile 文件名 SHA256` 可核对下载内容。

## 源码与第三方组件

### GitHub Pages

在线地址：<https://seu-peter.github.io/ExcelBomb/>。网页、字体、处理库和 Worker 全部由仓库提供；表格只在浏览器中处理。可将在线提供的 `ExcelBomb.html` 另存为本地文件后离线使用。

推送 `main` 中的网页或构建代码后，`.github/workflows/deploy-pages.yml` 自动构建并运行核心回归检查，然后仅发布静态网页资源和离线 HTML。也可在 Actions 中手动执行 **Deploy GitHub Pages**。仓库历史、测试表格、构建工具及安装包不作为站点内容发布。

### 从源码运行

可直接克隆公开源码，并使用 Python 3 启动本地服务：

```sh
git clone https://github.com/SEU-Peter/ExcelBomb.git
cd ExcelBomb
python3 site/scripts/local_server.py --serve
```

浏览器打开 <http://127.0.0.1:8769/>。也可直接打开仓库根目录的 `ExcelBomb.html`，无需安装开发工具。

修改网页后，使用 Node.js 18 或更新版本同步 Worker 和离线文件并运行核心检查：

```sh
cd site
npm run build:offline
npm test
```

现代版运行库已随源码附带，上述构建无需安装 npm 依赖。Win7 构建另外使用锁定的开发依赖和 Go 1.20.14；具体命令及浏览器测试方法见 [DEVELOPMENT.md](DEVELOPMENT.md)。

| 目录 / 文件 | 内容 |
| --- | --- |
| `site/dist/` | 网页、数据处理逻辑、生成的 Worker 与本地资源 |
| `site/src/`、`site/scripts/` | Worker 入口、离线构建与本地服务 |
| `site/win7/` | Win7 兼容层、原生安装/启动器及构建脚本 |
| `site/tests/` | 核心逻辑、真实 XLSX 读写和浏览器回归检查 |
| `test/` | 可手动体验功能的虚构测试表格 |
| `docs/releases/` | 各版本发布说明 |

GitHub 公开维护开发源码，GitHub Pages 发布静态网页，安装包通过 Release 附件分发；`releases/`、本机配置、依赖缓存和历史站点凭据不提交到仓库。网页功能代码通过 GitHub Actions 自动部署到 GitHub Pages；只有明确要求打包或生成 Release 时才另行生成安装包和 Release。
